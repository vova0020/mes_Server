# API для статистики операторов

## Обзор изменений

Добавлена функциональность для фильтрации статистики производства по операторам и получения списка операторов (пользователей с ролью 'operator').

---

## Изменения в существующих endpoint'ах

### 1. GET `/statistics/machine-production`

**Добавлен новый фильтр:**

- `operatorId` (number, опционально) - ID оператора для фильтрации

**Пример запроса:**
```
GET /statistics/machine-production?operatorId=5&startDate=2024-01-01&endDate=2024-12-31
```

**Все доступные фильтры:**
- `startDate` (string, ISO дата) - Период с
- `endDate` (string, ISO дата) - Период по
- `machineId` (number) - ID станка
- `orderId` (number) - ID заказа
- `stageId` (number) - ID этапа производства
- `operatorId` (number) - **НОВЫЙ** ID оператора

**Ответ:** Массив записей `MachineProductionRecord[]`

Каждая запись уже содержит информацию об операторе:
- `operatorId` (number | null) - ID оператора
- `operatorName` (string | null) - ФИО оператора

---

### 2. GET `/statistics/filter-options`

**Добавлено новое поле в ответ:**

```json
{
  "orders": [...],
  "materials": [...],
  "machines": [...],
  "stages": [...],
  "operators": [
    {
      "userId": 1,
      "firstName": "Иван",
      "lastName": "Иванов",
      "fullName": "Иван Иванов"
    }
  ]
}
```

**Новое поле `operators`** - массив пользователей с ролью 'operator'.

Каждый оператор содержит:
- `userId` (number) - ID пользователя
- `firstName` (string) - Имя
- `lastName` (string) - Фамилия
- `fullName` (string) - Полное имя (имя + фамилия)

---

## Новые endpoint'ы

### 3. GET `/statistics/operators`

**Описание:** Получить список всех пользователей с ролью 'operator'.

**Параметры:** Нет

**Ответ:**
```json
[
  {
    "userId": 1,
    "firstName": "Иван",
    "lastName": "Иванов",
    "fullName": "Иван Иванов",
    "position": "Оператор станка"
  },
  {
    "userId": 2,
    "firstName": "Петр",
    "lastName": "Петров",
    "fullName": "Петр Петров",
    "position": "Упаковщик"
  }
]
```

**Поля ответа:**
- `userId` (number) - ID пользователя
- `firstName` (string) - Имя
- `lastName` (string) - Фамилия
- `fullName` (string) - Полное имя
- `position` (string | undefined) - Должность (если указана)

**Сортировка:** По фамилии (lastName) в алфавитном порядке

---

## Примеры использования

### Получить статистику конкретного оператора за период
```
GET /statistics/machine-production?operatorId=5&startDate=2024-01-01&endDate=2024-01-31
```

### Получить статистику оператора на конкретном станке
```
GET /statistics/machine-production?operatorId=5&machineId=10
```

### Получить статистику оператора по конкретному заказу
```
GET /statistics/machine-production?operatorId=5&orderId=100
```

### Получить список всех операторов для фильтра
```
GET /statistics/operators
```

### Получить все фильтры (включая операторов)
```
GET /statistics/filter-options
```

## Связь операторов со станками

Операторы связываются со станками через таблицу `OperatorMachineBinding`.

### Автоматическое определение операторов:

При выполнении операции на станке система **автоматически** определяет всех операторов, привязанных к станку в момент выполнения:

1. **MachineOperationHistory** - для обычных этапов производства
   - При завершении операции создается запись для **каждого** активного оператора, привязанного к станку
   - Если к станку привязано 3 оператора, создается 3 записи с одинаковыми данными, но разными `operatorId`
   - Если нет привязанных операторов, создается одна запись с `operatorId = null`

2. **PackingTask** - для этапа упаковки
   - Поле `assignedTo` - ID оператора (упаковщика)
   - Определяется при назначении задачи упаковки

---

## Примечания

- Операторы определяются **автоматически** на основе привязок к станку в момент выполнения операции
- Если к станку привязано несколько операторов, создается отдельная запись для каждого
- Фильтр по `operatorId` работает как для обычных станков, так и для упаковки
- Список операторов включает только пользователей с ролью 'operator'
- Операторы сортируются по фамилии в алфавитном порядке
- **Фронтенду не нужно передавать `operatorId`** - система определяет его автоматически
