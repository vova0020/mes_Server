# API для управления заказами индивидуального производства

## Обзор

Модуль предоставляет функционал для создания заказов индивидуального производства из Excel файлов.

**Базовый путь:** `/custom-order-management`

## Endpoints

### 1. Загрузить и распарсить Excel файл

**POST** `/custom-order-management/upload`

Парсит Excel файл с деталями и возвращает распарсенные данные для предварительного просмотра.

#### Параметры запроса

- **Content-Type:** `multipart/form-data`
- **file** (required): Excel файл (.xls или .xlsx)

#### Формат Excel файла

Файл должен содержать колонки:
- **Код** или **Артикул** - код детали
- **Наименование** - название детали
- **Кол-во** или **Количество** - количество деталей

Парсер автоматически ищет эти колонки в первых 40 строках файла.

#### Пример ответа (успех)

```json
{
  "message": "Файл успешно обработан",
  "filename": "тестовый проект по индивидуалке.xls",
  "data": {
    "parts": [
      {
        "code": "DET-001",
        "name": "Столешница",
        "quantity": 5
      },
      {
        "code": "DET-002",
        "name": "Боковина левая",
        "quantity": 10
      }
    ]
  }
}
```

#### Ошибки

- **400 Bad Request** - Ошибка обработки файла
  - Файл не загружен
  - Неверный формат файла (не Excel)
  - Не найдены необходимые колонки
  - Нет корректных данных в файле

---

### 2. Сохранить заказ из распарсенного файла

**POST** `/custom-order-management/save-from-file`

Создает заказ индивидуального производства и сохраняет детали в базу данных.

#### Тело запроса

```json
{
  "orderNumber": "ORD-2024-001",
  "orderName": "Заказ на индивидуальное производство",
  "requiredDate": "2024-12-31",
  "parts": [
    {
      "code": "DET-001",
      "name": "Столешница",
      "quantity": 5
    },
    {
      "code": "DET-002",
      "name": "Боковина левая",
      "quantity": 10
    }
  ],
  "priority": 1
}
```

#### Параметры

- **orderNumber** (string, required) - Номер заказа
- **orderName** (string, required) - Название заказа
- **requiredDate** (string, required) - Требуемая дата выполнения (формат: YYYY-MM-DD)
- **parts** (array, required) - Массив деталей
  - **code** (string, required) - Код детали
  - **name** (string, required) - Название детали
  - **quantity** (number, required) - Количество (минимум 0.01)
- **priority** (number, optional) - Приоритет заказа (по умолчанию 0)

#### Пример ответа (успех)

```json
{
  "message": "Заказ для индивидуального производства успешно создан",
  "customOrderId": 1,
  "orderNumber": "ORD-2024-001",
  "partsCount": 2
}
```

#### Ошибки

- **400 Bad Request** - Ошибка валидации данных
  - Отсутствуют обязательные поля
  - Неверный формат данных

---

## Процесс работы

1. **Загрузка файла**: Пользователь загружает Excel файл через endpoint `/upload`
2. **Парсинг**: Сервер парсит файл и возвращает распарсенные данные
3. **Предварительный просмотр**: Фронтенд показывает пользователю распарсенные данные
4. **Редактирование** (опционально): Пользователь может изменить данные перед сохранением
5. **Сохранение**: Пользователь отправляет данные на endpoint `/save-from-file`
6. **Создание заказа**: Сервер создает заказ в таблице `custom_orders` и детали в таблице `custom_order_parts`

## Таблицы базы данных

### custom_orders
- `custom_order_id` - ID заказа
- `order_number` - Номер заказа
- `order_name` - Название заказа
- `completion_percentage` - Процент выполнения
- `created_at` - Дата создания
- `updated_at` - Дата обновления
- `completed_at` - Дата завершения
- `required_date` - Требуемая дата
- `status` - Статус (PRELIMINARY, APPROVED, LAUNCH_PERMITTED, IN_PROGRESS, COMPLETED, POSTPONED)
- `priority` - Приоритет

### custom_order_parts
- `custom_part_id` - ID детали
- `custom_order_id` - ID заказа
- `part_code` - Код детали
- `part_name` - Название детали
- `material_name` - Наименование материала
- `material_sku` - Артикул материала
- `quantity` - Количество
- `route_id` - ID маршрута обработки
- `status` - Статус детали (PENDING, IN_PROGRESS, COMPLETED)
- И другие поля для характеристик детали

## WebSocket уведомления

При создании заказа отправляется WebSocket событие:
- **Событие:** `custom-order:event`
- **Комнаты:** `room:masterceh`, `room:machines`, `room:machinesnosmen`, `room:technologist`, `room:director`
- **Данные:** `{ status: 'created', orderId: <customOrderId> }`

## Примечания

- Для индивидуального производства не требуется проверка справочников деталей
- Детали сохраняются напрямую из файла в таблицу `custom_order_parts`
- Материалы и маршруты могут быть назначены позже
- Максимальный размер файла: 10 МБ
